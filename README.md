# Networking Fundamentals

Hands-on networking labs created using Cisco Packet Tracer while studying CCNA fundamentals.

## Topics Covered

- Basic LAN connectivity
- IP addressing and subnetting
- DHCP configuration
- VLAN and inter-VLAN routing
- VTP, STP and RSTP
- Static routing and OSPF
- Standard and extended ACL
- NAT and PAT
- IPv6
- SSH and network device management
- SNMP and basic monitoring concepts
- GRE VPN

## Lab Structure

Each lab may include:

- Cisco Packet Tracer `.pkt` file
- Network topology
- Configuration notes
- Verification commands
- Screenshots
- Troubleshooting or fault scenario

## Tools Used

- Cisco Packet Tracer
- Cisco IOS CLI
- GitHub

## Disclaimer

These are self-practice labs created for learning and portfolio purposes.
